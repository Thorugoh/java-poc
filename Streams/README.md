## About Streams

- Introduced in Java 8, Streams provide a modern way to process collections of objects.
- They support functional-style operations, allowing for more concise and readable code.
- Streams can be created from various data sources, including collections, arrays, and I/O channels.
- They support operations like filtering, mapping, and reducing, enabling complex data processing tasks.


- Streams are lazy, meaning operations are not executed until a terminal operation is invoked.
